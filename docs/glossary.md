# ユビキタス言語定義(用語集)

作成日: 2026-08-27
参照元: `casemax_groupware_requirements.md`、`docs/product-requirements.md`、`docs/functional-design.md`
ステータス: ドラフト(要承認。実装で新たな用語が必要になった場合は随時追記する)

---

## 1. 使い方

本プロジェクトの会話・ドキュメント・コード上の命名で表記揺れが起きないよう、日本語のビジネス用語とコード上の英語表記を1対1で対応させる。新しい用語を追加する際は、この対応表に追記してからコードに反映する。

---

## 2. ドメイン用語・ビジネス用語 対応表

| 日本語(ドメイン用語) | 英語(コード上の表記) | 定義・補足 |
|---|---|---|
| 利用者 / 社員 | User | システムを利用する社員。氏名・ログインID・所属グループ等を持つ |
| 権限区分 | role | `admin`(管理者)/ `general`(一般社員)の2区分 |
| 所属グループ | Group | 部署等の単位。1人の利用者が複数グループに所属可能(多対多) |
| 退職(論理削除) | retire / status: "retired" | アカウントを物理削除せず、ログイン禁止のステータスに変更する処理。投稿者・更新者表示は保持される |
| お知らせ・掲示板 | Board / Post | 全社・部署別に投稿される告知。1件の投稿を `Post` と呼ぶ |
| 本文 | body(body_html) | リッチテキスト形式(サニタイズ済みHTML)で保存される投稿本文 |
| 既読管理 | read status | 投稿ごとに利用者が既読済みかを記録する仕組み |
| 一括削除 | bulk delete | 管理画面から最終更新日をFrom-To指定して投稿・添付ファイルをまとめて削除する機能 |
| 個人・チームカレンダー | Calendar / Calendar Event | 利用者個人の予定。`CalendarEvent` として保持 |
| 公開対象 | visibility | 予定を「誰に見せるか」を表す設定。値は `self`(自分)/ `all`(全員)の2択 |
| 非表示 | isHidden | 公開対象とは独立した設定。ONの場合、他人にはタイトル・詳細を隠し「予定あり」とだけ見せる |
| 週間ガントチャート | Week Gantt (Weekly Schedule View) | トップ画面に表示する、本日起点1週間×利用者を行に並べたスケジュール表示形式 |
| 表示グループ切替 | display group filter | 週間ガントで表示するグループ(部署)を切り替えるプルダウン |
| 月表示 | Month View | 個人1名分の予定をカレンダー形式(月単位)で表示する画面 |
| 祝日 | Holiday | 法定の国民の祝日。専用管理画面で管理者が年次登録するマスタデータ |
| 会社休日 | Company Holiday | 会社独自の休業日。通常の予定登録機能を使い、公開対象「全員」で誰でも登録可能 |
| 会議室予約 | Room Reservation | 会議室(`MeetingRoom`)に対する時間帯単位の予約 |
| 二重予約防止 | double-booking prevention | 同一会議室・同一時間帯の重複予約を防ぐ制御 |
| Googleカレンダー同期 | Google Calendar Sync | 個人予定を希望者のGoogleカレンダーへ双方向同期する機能 |
| オプトイン | opt-in | Googleカレンダー同期を利用するかどうかを利用者本人が選択できる方式(全員一律ではない) |
| セカンダリカレンダー | secondary calendar | プライバシー保護のため、私用カレンダーとは別に作成する社内予定専用のGoogleカレンダー |
| トークン失効 | token revoke | 退職時等にGoogleのrevoke APIを呼び出し、アプリのアクセス権を無効化する処理 |
| 会議候補日時の自動抽出 | Meeting Finder | 複数人の予定を横断して空き時間を計算し、候補日時を提示する機能 |
| 空き時間 / 予定あり | free / busy | 対象者の時間帯が空いているか埋まっているかを表す判定結果。非表示予定も内容不問でbusy扱いとする |
| 候補提示件数 | suggestion count | 会議候補日時の自動抽出で提示する件数(既定3件) |
| コピー用テキスト | copy text (share text) | 検索結果の候補日程を取引先向けメール文面としてコピーできる定型文 |
| ファイル共有 | File Sharing | フォルダ階層で管理するファイルのアップロード・ダウンロード機能 |
| フォルダ階層 | Folder Hierarchy | ファイルを整理するための親子構造を持つフォルダ |
| バージョン管理(ファイル) | File Version | 同一ファイルの更新履歴 |
| 操作ログ | Operation Log | 「誰が・いつ・何を編集/削除したか」を記録するログ。ゴミ箱の代替的な役割を担う |
| ゴミ箱機能 | Trash (not implemented) | 誤削除復元の仕組み。本プロジェクトでは意図的に実装しない方針(要件3-4・3-6) |
| トップ画面(ポータル) | Top Page / Portal | ログイン後にスケジュール・掲示板・ファイルの最新情報を集約表示する画面 |
| 表示件数設定 | display count setting | トップ画面の掲示板・ファイル欄に表示する件数。個人設定ではなく管理画面で全社員共通に設定 |
| 固定リンク | Permalink | 掲示板・ファイルの詳細画面に付与される、社内共有用の固定URL |
| 利用者管理 | User Management | 管理者限定で利用者の登録・編集・退職処理を行う管理画面機能 |
| 簡易アドレス帳 | address book (reference view, 未確定) | 一般社員が氏名・メールアドレス・所属グループを参照できる画面(要否未確認) |

## 3. UI/UX用語

| 日本語 | 英語(コード上の表記) | 定義・補足 |
|---|---|---|
| もっと見る | "View more" link | ウィジェットから一覧画面へ遷移するリンク |
| 新規登録 | "New" button | トップ画面ウィジェット・一覧画面双方に配置する新規投稿/アップロードへの導線ボタン |
| 前週 / 前日 / 本日 / 翌日 / 翌週 | prev-week / prev-day / today / next-day / next-week | 週間ガントの表示期間を操作するナビゲーションボタン |
| 本日起点 | anchored to today | ナビゲーション操作をリセットした際に戻る基準(常に本日を起点とする表示) |

## 4. コード上の命名規則(要約)

詳細は `docs/development-guidelines.md` の「命名規則」節を参照。本用語集の英語表記をそのまま変数名・テーブル名・APIパスのベースとして使用する。

- テーブル名・カラム名: 本表の英語表記をスネークケースにする(例: `is_hidden`, `updated_at`)
- コンポーネント名・クラス名: パスカルケース(例: `MeetingFinder`, `WeekGanttChart`)
- APIパス: ケバブケース(例: `/api/meeting-finder/search`)
