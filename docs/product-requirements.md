参照元: `casemax_groupware_requirements.md`(要件定義ドラフト、2026-08-24〜27ヒアリング内容含む)
ステータス: ドラフト(要承認)

## 1. プロダクトビジョンと目的

株式会社ケアマックスコーポレーション(親会社、利用者約120名)は現在サイボウズOfficeを有償契約しているが、実際に利用している機能は①お知らせ・掲示板、②個人・チームカレンダー、③ファイル共有の3つに限られている。

本プロダクトは、この**実利用機能に絞った置き換え型の軽量グループウェア**を自社開発することで、フル機能製品のライセンス費用を払い続ける非効率を解消することを目的とする。あわせて、追加要望として挙がった④会議室予約、⑤希望者向けGoogleカレンダー個人同期(双方向)、⑥会議候補日時の自動抽出、⑦トップ画面(ポータル)、⑧利用者管理を含める。

**目的はコスト削減(TCO最適化)であり、機能の多機能化ではない**。スコープ外の機能(ワークフロー・承認、勤怠管理、メール、報告書、ToDoリスト、プロジェクト管理等)は将来要望が出ても安易に追加せず、都度「本当に必要か」「サイボウズ側機能の部分復活の方が安いか」を比較検討する方針を製品原則とする。

## 2. ターゲットユーザーと課題・ニーズ

| ユーザー区分 | 人数目安 | 課題・ニーズ |
|---|---|---|
| 一般社員(全体) | 約120名 | 掲示板・カレンダー・ファイル共有をサイボウズOfficeと同水準以上の使い勝手で利用したい |
| 営業職(iPhoneユーザー) | 約40名 | 外出先でGoogleカレンダーアプリから予定確認・プッシュ通知を受けたい。グループウェア側・Google側どちらで編集しても同期してほしい(双方向) |
| 会議室利用者(全社員) | 約120名 | 会議室の空き状況確認、予約・変更・取消をダブルブッキングなく行いたい |
| 社外との打ち合わせ調整担当者 | 全社員 | 複数人の予定を突き合わせて候補日を探す作業を自動化し、取引先へのメール文面作成も効率化したい |
| 管理者(情シス/総務相当) | 少数 | 利用者管理、祝日設定、掲示板の一括削除、表示件数設定など運用管理を行いたい |
| 経営・意思決定者 | - | サイボウズOffice解約によるコスト削減効果を、開発・保守コストとのTCOで正しく判断したい |

**現状の課題(As-Is)**:
- サイボウズOfficeのフル機能ライセンスに対し、実利用は3機能のみでコスト効率が悪い(想定年額86万円〜144万円、2026年時点公開料金からの試算)。
- 会議候補日の調整は月表示カレンダーを目視確認しながら手作業で行っており非効率。
- Googleカレンダーとの連携がなく、外出先での予定確認・通知ができない。

## 3. 主要な機能一覧

| # | 機能 | 概要 |
|---|---|---|
| 1 | お知らせ・掲示板 | 全社/部署別投稿、既読管理、コメント、添付ファイル、リッチテキスト本文、管理者による一括削除 |
| 2 | 個人・チームカレンダー | 個人予定登録(公開対象・非表示設定)、他者予定閲覧、繰り返し予定、週表示/月表示 |
| 2-1 | 共通休日設定 | 祝日(管理画面での年次登録)、会社休日(通常予定登録機能を利用) |
| 2-2 | 会議室予約 | 会議室ごとの空き状況、予約・変更・取消、二重予約防止(Google双方向同期の対象外) |
| 2-3 | 個人Googleカレンダー同期 | 希望者(オプトイン)向けGoogle Calendar API双方向連携(セカンダリカレンダー方式) |
| 2-4 | 会議候補日時の自動抽出 | 複数人の空き時間を横断計算し候補日を提示、テキストコピー機能付き |
| 3 | ファイル共有 | フォルダ階層管理、アップロード/ダウンロード、バージョン管理、操作ログ(権限制御・ゴミ箱なし) |
| 4 | トップ画面(ポータル) | 週間ガントチャート形式のスケジュール、掲示板・ファイルの最新一覧を集約表示 |
| 5 | 利用者管理 | 氏名・メールアドレス・ログインID・パスワード・社員番号・所属グループ・権限区分の管理(管理者限定) |
| 6 | 固定リンク | 掲示板・ファイル共有の詳細画面に社内共有用の固定URLを表示・コピー |

スコープ外(明示): ワークフロー・承認、勤怠管理、メール送受信、報告書、アドレス帳(簡易参照機能を除く)、ToDoリスト、プロジェクト管理。

## 4. 成功の定義

- サイボウズOffice契約(3機能分)を解約し、年間ライセンス費用(概算86万円〜144万円)を削減できること。
- 上記3機能について、現行サイボウズOfficeで実際に使われている水準の使い勝手を損なわないこと。
- 開発・保守工数(機会費用含む)が、削減できるライセンス費用に対して合理的な投資回収年数に収まること(7章のROI枠組みで判断)。
- 移行後、120名の利用者が大きな業務停滞なく新システムへ移行できること。

## 5. ビジネス要件

- 認証はSSO(Google Workspace/Microsoft 365等)連携不要。独自ID/パスワード発行方式とする。
- 社員の大半は個人のGmailアカウント利用であり、Google Workspace法人契約者は少数。Googleカレンダー連携はこの前提に対応した設計(個人ごとのOAuth同意)とする。
- 開発・保守はアルゴのエンジニアチームが担う想定であり、本業(受託開発・EC運営)への影響を踏まえた体制検討が必要。
- 個人情報(氏名・所属・連絡先等)を扱うため、個人情報保護法上の安全管理措置について本格開発着手前に専門家確認を推奨する。

## 6. ユーザーストーリー

- 一般社員として、トップ画面を開くだけで今週の自分とチームの予定、最新のお知らせ、最新のファイル更新を把握したい。
- 一般社員として、他人に見せたくない予定は「非表示」にして、存在だけ知らせたい。
- 営業職として、外出先のiPhoneでGoogleカレンダーアプリを開けば、会社の予定をプッシュ通知で受け取りたい。
- 管理者として、退職者のアカウントを削除する操作だけで、Googleカレンダー同期の解除まで自動で完了してほしい。
- 打ち合わせ調整担当者として、対象者を選ぶだけで空いている候補日を3件自動抽出し、そのままメール文面としてコピーしたい。
- 管理者として、放置された古いお知らせと添付ファイルを、期間指定でまとめて削除したい。
- 社員として、掲示板やファイルの詳細画面の固定リンクを同僚に送るだけで、その画面へ直接案内したい。

## 7. 受け入れ条件

- お知らせ・掲示板: リッチテキストで投稿でき、一覧・トップ画面でも装飾が保持される。投稿はサニタイズされXSSが発生しない。管理画面から期間指定一括削除ができ、実行前に対象件数がプレビュー表示される。
- カレンダー: 予定の公開対象は「自分」「全員」の2択、非表示チェックを独立して設定できる。週間ガント表示(前週/前日/本日/翌日/翌週ナビゲーション)と、個人の月表示への遷移ができる。
- 会議室予約: 二重予約が発生しない。Google側での直接編集は会議室予約に反映されない。
- Googleカレンダー同期: 個人ごとにオプトインでき、セカンダリカレンダー経由で双方向同期する。退職時のアカウント削除操作で同期解除(予定削除→トークン失効)が自動実行される。
- 会議候補日時の自動抽出: 部署選択→メンバーチェックボックスで対象者を選べる。平日9:00〜17:30固定、検索期間は既定2週間で変更可能、所要時間は30分単位選択、候補は3件提示。テキストコピーで定型文が生成される。
- ファイル共有: フォルダ階層で整理でき、全社員が閲覧・編集・削除可能。操作ログに誰が・いつ・何をしたか記録される。
- トップ画面: 表示件数は管理画面で全社員共通に設定される。掲示板・ファイルのウィジェットから新規登録画面へ直接遷移できる。
- 利用者管理: 管理者限定で氏名・メール・ログインID・パスワード(ハッシュ化)・社員番号・所属グループ(複数可)・権限区分を管理できる。
- 固定リンク: 掲示板・ファイルの詳細画面でURLを表示・コピーでき、未ログイン状態でアクセスするとログイン後に目的画面へ遷移する。

## 8. 機能要件

要件定義書「3. スコープ定義」に列挙された各機能の最低限要素、および3-1〜3-11の確定仕様を機能要件の正とする。詳細な画面仕様・データモデルは `functional-design.md` に記載する。

## 9. 非機能要件

| 項目 | 要件 |
|---|---|
| 認証 | 独自ID/パスワード発行。パスワードはハッシュ化保存し再表示不可 |
| 権限管理 | 掲示板・カレンダーは部署単位での権限設定対象。ファイル共有は権限制御なし(全社員フルアクセス) |
| 規模対応 | 同時アクセス120名程度を安定処理できる設計。過剰インフラは不要 |
| データ移行 | サイボウズOfficeからの掲示板投稿・カレンダー予定・ファイルの移行要否・範囲は要確認 |
| バックアップ・可用性 | 日次バックアップを本体Webサーバーとは物理的に別の場所に保存。業務時間帯の稼働保証 |
| セキュリティ | HTTPS通信、掲示板本文のサニタイズ(XSS対策)、ファイル共有・掲示板の操作ログ記録 |
| 外部API連携 | Google Calendar API(個人オプトイン、OAuthトークン安全管理、Webhook定期更新、退職時のトークン失効) |

## 未確定事項(要件定義書 4章・10章より抜粋)

- トップ画面の表示件数デフォルト値、表示範囲、レイアウトの個人カスタマイズ要否
